# Icons

- `logo-float*.png`: the OpenMoat floating crocodile (Crocodile Labs).
- `agent-claude*.png`, `agent-codex*.png`, `agent-cursor*.png`: rendered from the provider
  icons in [CodexBar](https://github.com/steipete/CodexBar) (`Sources/CodexBar/Resources/ProviderIcon-*.svg`),
  MIT License, Copyright (c) Peter Steinberger. The marks belong to Anthropic, OpenAI and
  Anysphere and are used only to name the agent each row is about.
- The other agents OpenMoat reports (OpenClaw, GitHub Copilot CLI, pi, Gemini CLI) have no
  icon yet and are drawn with a generic one; OpenMoat's own parts that write events (the
  network proxy, the MCP proxy, `openmoat run`) are named, not drawn.
