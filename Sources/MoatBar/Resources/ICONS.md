# Icons

- `logo-float*.png`: the OpenMoat floating crocodile (Crocodile Labs).
- `agent-claude*.png`, `agent-codex*.png`, `agent-cursor*.png`, `agent-copilot*.png`,
  `agent-pi*.png`, `agent-gemini*.png`: rendered from the provider icons in
  [CodexBar](https://github.com/steipete/CodexBar) (`Sources/CodexBar/Resources/ProviderIcon-*.svg`),
  MIT License, Copyright (c) Peter Steinberger. The marks belong to Anthropic, OpenAI,
  Anysphere, GitHub, the pi project and Google and are used only to name the agent each row
  is about.
- `agent-openclaw*.png`: the pixel lobster from [OpenClaw](https://github.com/openclaw/openclaw)
  (`docs/assets/pixel-lobster.svg`), MIT License, Copyright (c) OpenClaw Foundation.
- Every agent icon is a black shape on a transparent background at 16, 32 and 48 px; both
  apps draw it as a template (alpha only) in the row's text colour. OpenMoat's own parts that
  write events (the network proxy, the MCP proxy, `openmoat run`) are named, not drawn.
